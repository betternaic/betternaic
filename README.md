# BetterNaic

A community-built local government portal for **Naic, Cavite**, part of the
[BetterGov.ph LGU Directory](https://github.com/jmacj/better-lgu-directory).

**Status:** 🔵 Planned — registered in the directory, build not yet started.

## Goal

Make Naic's public information easy to find: office directories, contact
details, service requirements, announcements, and forms — in one place,
readable on a phone, with no login.
